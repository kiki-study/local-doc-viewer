# Local Doc Viewer

ローカルに保存してある Markdown（.md）と HTML を、ブラウザのタブで一覧・全文検索・閲覧する Chrome 拡張機能です。
Mermaid の図とコードの色付けに対応しています。拡張機能の権限はなく、ファイルの内容を外部に送信しません。

A Chrome extension to browse, full-text search, and read local Markdown and HTML files in a browser tab.
Supports Mermaid diagrams and syntax highlighting. It requires no permissions and never sends your files anywhere.
