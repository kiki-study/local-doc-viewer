# Local Doc Viewer

A Chrome extension to browse, full-text search, and read the Markdown and HTML files on your computer in a browser tab.

- Lists the `.md` and `.html` files in the folders you choose as a tree, with full-text search across names and contents
- GitHub-style Markdown, Mermaid diagrams, syntax highlighting, table of contents, and dark mode
- HTML files are shown in an isolated page; scripts inside them are blocked until you allow them for that folder
- Requires no permissions. Files are read-only, and the extension itself never sends your files anywhere
- Available in English and Japanese (follows Chrome's display language)

**[Install from the Chrome Web Store](https://chromewebstore.google.com/detail/aenecamccenmkmlpfgjgggjjiamcngfo)** (Chrome 147 or later)

ローカルに保存してある Markdown（.md）と HTML を、ブラウザのタブで一覧・全文検索・閲覧する Chrome 拡張機能です。

- 選んだフォルダの中の `.md` / `.html` をツリーで一覧にし、ファイル名と本文を全文検索できます
- GitHub と同じ書き方の Markdown、Mermaid の図、コードの色付け、目次、ダークモードに対応しています
- HTML は隔離したページで表示します。中のスクリプトは、そのフォルダで許可するまで動きません
- 拡張機能の権限はありません。ファイルは読むだけで、拡張機能そのものがファイルの内容を外部に送ることはありません
- 画面は日本語と英語に対応しています（Chrome の表示言語に従います）
